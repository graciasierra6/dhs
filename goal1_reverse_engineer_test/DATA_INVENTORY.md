### Expected indicator coverage

- DRC: 26 provinces x 8 indicators = 208 rows.
- Ethiopia: 11 regions x 7 indicators = 77 rows.
- Nigeria: 37 states/FCT x 8 indicators = 296 rows.
- Total: 74 areas and 581 area-indicator rows.

The standard indicator set is wasting, anemia among women, malaria RDT
positive, zero-dose, first birth before age 20, facility delivery, fever care
seeking, and ANC4+. Ethiopia has no malaria-RDT series in the retained inputs.

## Analytical rules checked during build

Rows where `composite_set == "severe"` are excluded. Composite rank 1 is best.

`pp_change_10yr_recoded` is risk aligned: positive always means worsening. The
sign is reversed for facility delivery, fever care seeking, and ANC4+ because
higher coverage is beneficial.

Threshold `T` is the type-7 25th percentile of the absolute risk-aligned changes,
calculated independently for each indicator within each country:

- change below `-T`: improving;
- change above `T`: worsening; and
- otherwise: non-significant change.

Each country's worsening-count map sums these classifications by first-level
administrative area. Every reference count and indicator membership list is
checked against the source calculation.

### `data/worsening_count_threshold_distributions.csv`

This generated audit table has 581 rows: one for every country, indicator, and
administrative area. Within each country-indicator group, rows are ordered from
most improving to most worsening. The file includes:

- observed latest estimate and prevalence/change ranks;
- risk-aligned percentage-point change and its absolute magnitude;
- the type-7 25th-percentile threshold and both `-T`/`+T` cutoffs;
- final improving, non-significant, or worsening classification; and
- binary contributions to the improving, non-significant, and worsening counts.

The file is regenerated by `render.R`, then independently recomputed and
compared by `validate.R`.

## Supplied profile sources

`region_profile_numbers.csv` contains 581 rows: one latest indicator record for
every displayed country, area, and indicator. `region_profile_mortality.csv`
contains 222 rows: IMR, NMR, and U5MR for all 74 areas. The mortality rows are
already rendered as the lower distribution block in each supplied profile PNG;
they are not added as separate browser-generated charts.

The latest U5MR values are also checked against `data/mortalityunder5.csv` using
the following filters:

| Country | ISO | Indicator | `window_mid` | `survey_year` |
|---|---|---|---:|---:|
| DRC | DRC | U5MR | 2022 | 2023 |
| Ethiopia | ETH | U5MR | 2022 | 2025 |
| Nigeria | NGA | U5MR | 2022 | 2024 |

The build stops unless every supplied profile row matches the dashboard data,
every area has one IMR, NMR, and U5MR row, every estimate falls within its
retained 95% confidence interval, and every latest U5MR value matches the
existing audit input.

## Boundary provenance

`data/reference/admin1_boundary_manifest.csv` pins public geoBoundaries metadata,
download variants, feature counts, and hashes. `admin1_feature_reference.csv`
pins every public shape name, dashboard label, subdivision code, feature order,
and geographic bounding box/center.

The supplied HTML had 43 incorrect name-to-shape references: six in the
Ethiopia indicator map and 37 in the Nigeria current-prevalence map. The
reconstruction replaces those references from the pinned feature manifest, and
the map validator rejects any future swapped name-to-geometry assignment.

Known labels reconciled in memory include `Tanganika`/`Tanganyika`, Ethiopia
Benishangul and Harari variants, and Nigeria FCT/Abuja variants. Source files are
not silently rewritten.
